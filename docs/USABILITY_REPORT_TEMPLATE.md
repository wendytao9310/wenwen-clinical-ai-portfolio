# Evidence & Safety Lab — 可用性测试报告模板

## 1. 测试范围

- 版本：
- 测试日期：
- 招募方式：
- 参与人数：
- 角色构成：
- 数据范围：仅内置合成场景 / 完全虚构场景

本测试评估界面可理解性、任务流程和安全边界，不评估临床有效性、监管合规或患者结局。

## 2. 核心任务

1. 选择一个示例场景并生成安全与证据卡；
2. 找到停止条件和证据缺口；
3. 查看评估计划；
4. 下载评测报告；
5. 记录问题和建议。

## 3. 汇总结果

| 指标 | 结果 | 计算说明 |
|---|---:|---|
| 独立完成率 | 待填写 | 独立完成人数 / 参与人数 |
| 中位完成时间 | 待填写 | 分钟，报告范围 |
| STOP 状态识别率 | 待填写 | 正确识别人数 / 完成该任务人数 |
| 报告导出成功率 | 待填写 | 成功导出人数 / 尝试人数 |
| 主观难度 | 待填写 | 1–5分，中位数与范围 |
